## Reviewed implementation decisions

1. Q option bit encoding is independent because the existing classic codec rejects part of the 20-bit NUM range. Classic behavior is unchanged.
2. Decoder performs a second pass only for Q-bearing packets, preserving malformed classic options and Request-Tag as well. Mixed-option validation takes precedence over malformed individual values.
3. Unsupported Q responses are silently dropped rather than dispatched or answered with a request-style error.
4. Only CON rejection ACKs enter the existing response cache; fresh-MID NON errors are not cached under unrelated request keys.
5. Body size bounds payload bytes. The manager owns active-body reservations, identity/token budgets, and expiry; adapter-owned wire messages remain outside its accounting.
